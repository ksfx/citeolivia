# CiteOlivia

Literatur- und Referenzverwaltung. Die Dokumentation steht im KSFX-Wiki:

- **CiteOlivia**: Funktionen, Architektur, Datenmodell, Entwicklung
- **Testdeployment**: bauen, starten auf 8080, Datenbank-Schutz, Backups
- **CI**: Corporate Design und Logos

Kurz: `./mvnw verify` baut und testet, `scripts/run.sh` deployt auf Port 8080 (mit Backup der Datenbank).
